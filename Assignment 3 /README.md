# ECON 3916 — Assignment 3: Causal Inference & Non-Parametric Methods

## Overview

This notebook applies a suite of non-parametric and causal inference techniques to three auditing scenarios drawn from a fictional gig-economy platform (SwiftCart). Each phase is designed to demonstrate the mathematical machinery underlying modern applied econometrics — with a strict prohibition on high-level wrappers (e.g., `scipy.stats.bootstrap`, `scipy.stats.permutation_test`) in favor of manual numpy implementations.

---

## Structure

### Phase 1 — Zero-Inflated Bootstrap (Driver Tips)

**Context:** A labor union challenges SwiftCart's reported "Median Driver Compensation." Tip data is zero-inflated (40% of observations are exactly $0) and right-skewed, rendering the Central Limit Theorem unreliable for small audits.

**Methods:**
- Synthetic data generated by combining 100 zero-tips with 150 draws from `Exponential(scale=5.0)` — 250 observations total
- Manual bootstrap engine: 10,000 resamples with replacement using `np.random.choice`
- Median computed per resample; 95% CI extracted via `np.percentile([2.5, 97.5])`

**Result:**
```
Sample Median:              0.7553
Bootstrap 95% CI:           [0.2643, 1.3636]
```

**Key insight:** The CI is asymmetric (upper half-width ~0.61 vs. lower ~0.49), reflecting the right skew of the exponential component. A symmetric parametric CI would misrepresent this structure.

---

### Phase 2 — Permutation Test (Routing Algorithm A/B Test)

**Context:** Engineering claims a new "Batch Routing" algorithm reduces delivery times. The treatment group contains extreme upper-bound outliers from crash loops, violating the homoscedasticity assumption of a standard t-test.

**Methods:**
- Control: `Normal(mean=35, sd=5)`, n=500
- Treatment: `LogNormal(mean=3.4, sigma=0.4)`, n=500
- Manual permutation test: 5,000 iterations using `np.random.permutation`, split into pseudo-groups of 500, difference in means computed per shuffle
- Empirical p-value: proportion of permuted differences ≥ |observed difference|

**Key insight:** The permutation test makes no distributional assumptions and directly computes exact p-values from the empirical null distribution — the correct approach when homoscedasticity is violated.

---

### Phase 3 — Propensity Score Matching (SwiftPass Loyalty Program)

**Context:** Marketing claims SwiftPass subscribers spend 300% more per month, justifying a doubled acquisition budget. High-volume "power users" self-select into the program, introducing severe selection bias.

**Dataset:** `swiftcart_loyalty.csv` — 8,941 observations with covariates: `pre_spend`, `account_age`, `support_tickets`, `subscriber` (treatment indicator), `post_spend` (outcome).

**Methods:**
1. Naive SDO (Simple Difference in Means) — raw comparison of subscriber vs. non-subscriber post-spend
2. Logistic Regression (`sklearn`) on pre-treatment covariates to estimate propensity scores
3. 1-to-1 Nearest Neighbor Matching (`sklearn.NearestNeighbors`) on propensity score
4. ATT (Average Treatment Effect on the Treated) computed on matched sample
5. Love Plot (Standardized Mean Differences) visualizing covariate balance before and after matching

**Results:**
```
Naive SDO:    17.5707
ATT (PSM):     9.9139
Difference:    7.6568  (~44% of the naive estimate is pure selection bias)
```

**Key insight:** The naive SDO is inflated by ~77% relative to the true causal effect. PSM collapses `pre_spend` SMD from ~0.65 to ~0.01, confirming that pre-existing spending habits — not the program itself — drove most of the raw difference.
